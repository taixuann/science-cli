Keysight B1500A Parsers

Lightweight header parsers for Keysight B1500A semiconductor analyzer CSV files. Exports set voltage, compliance, sweep range, and repeat count from CSV headers. All heavy endurance parsing is deliberately external — handled by plot_endurance_hot.py in the sci-keysight-endurance skill following the pre-processing contract.

4 items · intentional design decisions
✗
No Measurement Result section parser

The Measurement Result section in v2 endurance files is too complex for a general-purpose tool: variable column counts, nested cycle structures, mixed raw_cycles data. Handled externally by plot_endurance_hot.py.

✗
No raw_cycles placeholder replacement

Some v2 endurance files use placeholder tokens in raw_cycles that require lookup tables. Not worth generalizing — the external script handles this case-by-case.

✗
No WGFMU endurance format handling

WGFMU produces highly instrument-specific binary-like CSV. Each lab configures WGFMU differently. A general parser would be fragile. External script handles known formats.

✗
No per-pulse STP/PPF format handling

STP (single-pulse) and PPF (paired-pulse) formats have different schema per study. Better to pre-process externally and feed clean columns to sci plot.

External processing pipeline

All heavy Keysight endurance CSV parsing is deliberately external. The tool does not attempt to parse the 290k-line endurance files inline. Instead, a pre-processing step produces clean data that sci plot reads directly.
